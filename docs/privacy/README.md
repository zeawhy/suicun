## 一致性声明

页面内容（`index.html` 中文、`en.html` 英文）与 App 内隐私政策页面
`lib/features/settings/presentation/privacy_policy_page.dart`（常量 `_privacyPolicyZh` /
`_privacyPolicyEn`）逐段保持一致。**更新隐私政策时，两边必须同步修改。**

生效日期标注在页面标题下方（当前为 2026-10-19）。
