## 1. 您的应用是否会收集或共享用户数据？

**收集：是**（本地收集，见下表）
**共享：否**（不与任何第三方共享数据）

---

## 2. 收集的数据类型与用途

| 数据类型 | 是否收集 | 用途 | 是否为可选 | 说明 |
|---|---|---|---|---|
| 照片和视频（证件照片） | 是 | 应用功能 | 是（用户主动拍摄/选择） | AES-256-GCM 加密后存于应用私有目录 `id_photos/`；image_picker 临时文件随即删除；**不写入系统相册** |
| 个人信息（用户输入的记录内容：密码、联系人、证件号等） | 是 | 应用功能 | 是（用户主动输入） | 仅存本地 SQLite；无账号系统；可通过「设置 → 清除全部数据」彻底删除 |
| 文件和文档（WebDAV 同步时） | 是 | 应用功能 | 是（用户自行配置才启用） | 仅在用户启用 WebDAV 同步时，数据在**用户设备 ↔ 用户自己的服务器**之间直接传输（强制 HTTPS）；开发者无法访问 |
| 生物识别（指纹/面容） | 否（仅调用系统 API） | 应用功能（应用锁） | 是 | 生物信息由操作系统管理，应用不收集、不存储 |

**不收集**：位置信息、联系人列表、通话记录、短信、麦克风、设备 ID、广告 ID、崩溃日志、诊断数据、使用统计。

---

## 3. 数据处理方式（Play 要求逐项声明）

### 数据是否在传输过程中加密？
- **是**。WebDAV 同步强制要求 `https://`（`lib/features/sync/webdav_sync_provider.dart:35` 校验 URL 前缀）；未启用同步时数据不出设备。

### 用户能否要求删除数据？
- **是**。应用内「设置 → 清除全部数据」可彻底删除本地所有数据（含加密照片）；删除记录时关联的加密照片文件同步删除（`deleteIdPhotosForRecord`）。

### 是否遵循 Play 家庭政策？
- 不适用（非儿童应用）。

### 是否有独立的安全审查？
- 否。

## 4. 权限声明对照（供「应用权限」部分参考）

| 权限 | 用途 | 申请时机 |
|---|---|---|
| CAMERA | 仅用于拍摄证件照片，照片加密存应用私有目录 | 用户在证件表单点「拍照」时按需申请，启动时不申请 |
| USE_BIOMETRIC | 应用锁解锁（指纹/面容） | 用户在设置中启用应用锁时 |
| INTERNET | 仅用于用户自配置的 WebDAV 同步 | 用户启用同步时 |
| （无存储权限） | 选择照片走系统 Photo Picker（Android 13+）；无「保存到相册」功能 | — |

**特别说明**：`gal` 插件已从依赖中移除（2026-10-19 PR #33，死依赖从未被调用）；应用**没有**「保存到相册」功能，符合 README「照片不进相册」承诺。

---

## 5. 第三方 SDK / 数据共享

- **无广告、无第三方 SDK、无统计上报**（应用内隐私政策原文）。
- WebDAV 同步的数据接收方是**用户自己配置的服务器**，不属于第三方数据共享（用户自主行为，开发者无法访问）。
